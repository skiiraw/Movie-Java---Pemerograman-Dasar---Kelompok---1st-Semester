BIOSKOP UB - PROGRAM JAVA CONSOLE

Pastikan JDK terpasang.
Buka terminal di folder ini dan jalankan:
  javac *.java
  java Main

Di Windows PowerShell / CMD, perintah sama.
Pilih 1 untuk melakukan simulasi pemesanan dan pembayaran.
Tanggal transaksi menggunakan zona waktu Asia/Jakarta (WIB).
Pembayaran adalah simulasi, bukan transaksi bank/QRIS nyata.
Status kursi tidak disimpan setelah aplikasi ditutup.
Semua file diletakkan di satu folder (default package) agar kompatibel.
